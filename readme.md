# dota2statsbot
круто статы фурри гифки е621

## требования

клонирование репозитории
```bash
git clone https://github.com
cd dota2statsbot
```

зависимости
```bash
pip install -r requirements.txt
```

## запуск
```bash
python main.py
```

## .env переменные

- `BOT_TOKEN` - токен дискорд бота
- `E621_API`,
- `E621_LOGIN` - API-ключ и логин на сайте e621.net
